# Shadowrocket Rules RU

[English](README.md) | [Русский](README.ru.md)

Модульный проект правил маршрутизации Shadowrocket для пользователей из России.
Основная идея — направлять российские сервисы напрямую, а выбранные зарубежные
сервисы через существующую у пользователя политику `PROXY`.

![Демонстрация Shadowrocket](assets/intro.gif)

> После установки обязательно проверьте маршрутизацию. Доступность сервисов и их
> доменная инфраструктура со временем меняются.

## Архитектура проекта

```text
Shadowrocket/
├── base/
│   └── base.conf          # общая основа конфигурации
├── modules/               # дополнительные модули правил
├── builds/                # готовые конфигурации MINIMAL, ADVANCED и FULL
└── catalog/
    └── MODULES.md         # каталог модулей и Raw-ссылок
docs/                      # установка, синтаксис и свои правила
assets/                    # изображения для документации
```

## Готовые профили

| Профиль | Для кого предназначен |
|---|---|
| `MINIMAL` | Выбранные соцсети и стриминг через прокси, остальной неопознанный трафик напрямую |
| `ADVANCED` | Российские сервисы напрямую, остальной неопознанный трафик через прокси |
| `FULL` | Расширенная маршрутизация, privacy/crypto и URL-перенаправления |

Готовые профили предназначены для пользователей, которые не хотят собирать
конфигурацию вручную. Опытный пользователь может взять базовый файл и подключить
только необходимые модули из каталога.

Модули намеренно являются самодостаточными, поэтому отдельные правила могут
пересекаться. Скрипт `scripts/build-configs.sh` создаёт готовые профили и удаляет
из них полностью одинаковые правила.

## Требования

- приложение Shadowrocket на iOS или iPadOS;
- настроенный прокси-сервер или политика с именем `PROXY`;
- режим глобальной маршрутизации Shadowrocket, использующий активную конфигурацию.

В репозитории находятся только правила маршрутизации. Проект не предоставляет
прокси-серверы или VPN-доступ и сам по себе не гарантирует анонимность.
