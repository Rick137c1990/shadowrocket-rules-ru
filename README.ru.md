# Shadowrocket Rules RU

[English](README.md) | [Русский](README.ru.md)

[![Проверка правил](https://github.com/Rick137c1990/shadowrocket-rules-ru/actions/workflows/validate.yml/badge.svg)](https://github.com/Rick137c1990/shadowrocket-rules-ru/actions/workflows/validate.yml)

Модульные правила маршрутизации Shadowrocket для пользователей, подключающихся
из России.

## Почему появился этот проект

Я создал этот проект для собственного ежедневного использования. Из-за
ограничений доступа в России некоторые зарубежные сервисы приходится направлять
через прокси. При этом банки, государственные порталы, маркетплейсы и другие
российские сервисы обычно надёжнее работают с российским IP-адресом. Постоянно
поддерживать все исключения вручную на iPhone неудобно.

Поэтому проект поддерживает два равноправных сценария:

- установить готовый профиль и сразу начать работу;
- использовать базовую конфигурацию и одним нажатием включать или отключать
  независимые модули в Shadowrocket.

## Что такое Shadowrocket

[Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118) — платное
сетевое приложение для iOS и iPadOS. Оно подключается к предоставленному
пользователем прокси-серверу и распределяет трафик по доменам, IP-адресам,
GeoIP, протоколам и правилам перенаправления.

В этом репозитории находятся только правила маршрутизации. Проект **не
предоставляет** прокси-сервер, VPN-подписку, учётные данные или доступ к сети.

## Выберите способ использования

### Готовые профили

| Профиль | Поведение по умолчанию | Назначение |
|---|---|---|
| [`minimal.conf`](shadowrocket/builds/minimal.conf) | Неопознанный трафик использует `DIRECT` | Через `PROXY` идут только распространённые соцсети, мессенджеры и streaming-сервисы |
| [`advanced.conf`](shadowrocket/builds/advanced.conf) | Неопознанный трафик использует `PROXY` | Российские сервисы работают напрямую, остальной трафик идёт через прокси |
| [`full.conf`](shadowrocket/builds/full.conf) | Неопознанный трафик использует `PROXY` | Advanced плюс privacy, crypto и URL Rewrite |

### Независимые модули

Каждый файл в [`shadowrocket/modules`](shadowrocket/modules) работает
самостоятельно. Например, можно включить AI и инструменты разработчика без
streaming или временно отключить модуль социальных сетей одним нажатием.

Некоторые домены намеренно встречаются в нескольких модулях. Это позволяет
каждому модулю работать независимо. При создании готовых профилей генератор
удаляет полностью одинаковые правила.

- [Подробное описание модулей](docs/modules.ru.md)
- [Инструкция по установке](docs/instructions.ru.md)
- [Синтаксис и собственные правила](docs/manual.ru.md)

## Структура репозитория

```text
shadowrocket/
├── base/                  # общая основа конфигурации
├── modules/               # независимые модули, которые можно переключать
├── builds/                # готовые профили minimal, advanced и full
├── catalog/               # краткий индекс модулей и Raw-ссылки
└── custom/                # шаблон собственных правил
scripts/
├── build-configs.sh       # воспроизводимый генератор профилей
├── validate-rules.py      # строгая проверка структуры и синтаксиса
├── lint-rules.py          # поиск конфликтов, перекрытий и ошибок порядка
└── check-domains.py       # необязательная проверка состояния DNS
```

## Проверка проекта

```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
./scripts/build-configs.sh
./scripts/validate-configs.sh
git diff --exit-code
```

GitHub Actions запускает эти проверки при каждом push и pull request. Отдельный
еженедельный workflow формирует информационный DNS-отчёт и не блокирует обычную
разработку.

## Важное предупреждение

- Пользователь самостоятельно отвечает за прокси, настройку устройства,
  безопасность и соблюдение применимого законодательства и правил сервисов.
- Доступность сервисов и их доменная инфраструктура могут измениться без
  предупреждения.
- Успешная DNS-проверка не означает, что сервис доступен из конкретной сети или
  страны.
- Правила не гарантируют анонимность и защиту от утечек DNS, WebRTC, IP или
  данных на уровне приложений.
- Перед постоянным использованием проверьте банки, Госуслуги, авторизацию,
  звонки и платёжные приложения.
- Проверяйте сторонние конфигурации перед импортом в Shadowrocket.

Используйте проект на свой риск.
