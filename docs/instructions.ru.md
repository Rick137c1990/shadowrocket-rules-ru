# Добавление правил в Shadowrocket

[English](instructions.md) | [Русский](instructions.ru.md)

Инструкция показывает два способа: установка готового профиля и добавление
независимых модулей, которые можно включать и отключать по отдельности. На
скриншотах используется русский интерфейс Shadowrocket. По мере развития проекта
названия модулей на скриншотах могут отличаться от актуальных имён файлов.

## Перед началом

Потребуются:

- Shadowrocket из [App Store](https://apps.apple.com/app/shadowrocket/id932747118);
- рабочий прокси-узел, назначенный политике с именем `PROXY`;
- доступ к Raw-ссылкам GitHub.

Репозиторий содержит только правила маршрутизации. Он не предоставляет
прокси-сервер, подписку, учётные данные или доступ к сети.

## Вариант A: готовый профиль

Используйте этот способ для самой простой установки.

1. Выберите файл в [`shadowrocket/builds`](../shadowrocket/builds):
   `minimal.conf`, `advanced.conf` или `full.conf`.
2. Откройте файл на GitHub и нажмите **Raw**.
3. Скопируйте Raw URL.
4. В Shadowrocket откройте вкладку **Настройка** и через действие загрузки или
   импорта добавьте URL удалённой конфигурации.
5. Выберите загруженную конфигурацию. Рядом с активной конфигурацией должна
   появиться галочка.
6. Вернитесь на главный экран, выберите прокси-узел и включите Shadowrocket.

Не устанавливайте готовый профиль как модуль. Профиль содержит полную
конфигурацию, а модуль является дополнительным набором правил для уже
существующей конфигурации.

## Вариант B: независимые модули

Используйте этот способ, если хотите одним нажатием включать или отключать
отдельные группы правил.

### 1. Откройте «Настройка»

На главном экране Shadowrocket нажмите вкладку с папкой **Настройка** внизу.

<p align="center"><img src="../assets/screenshots/01-open-config.png" width="320" alt="Главный экран Shadowrocket со стрелкой на вкладку Настройка"></p>

### 2. Выберите локальную конфигурацию

Выберите локальную конфигурацию, к которой будут подключены модули. Галочка
показывает используемую конфигурацию. Затем откройте пункт **Модули** в верхней
части страницы.

<p align="center"><img src="../assets/screenshots/02-open-modules.png" width="320" alt="Экран Настройка с локальной конфигурацией и пунктом Модули"></p>

### 3. Добавьте модуль

На экране «Модули» нажмите **+** в правом верхнем углу. Уже добавленные модули
можно включать и отключать с помощью галочек.

<p align="center"><img src="../assets/screenshots/03-add-module.png" width="320" alt="Экран Модули со стрелкой на кнопку добавления"></p>

### 4. Вставьте Raw URL

Откройте нужный файл в [`shadowrocket/modules`](../shadowrocket/modules), нажмите
**Raw** на GitHub и скопируйте адрес из браузера. Вставьте его в окно **Загрузить
с URL** и нажмите **Загрузка**.

<p align="center"><img src="../assets/screenshots/04-enter-url.png" width="320" alt="Окно Shadowrocket для загрузки модуля по URL"></p>

Повторите действия для каждого нужного модуля. Выбрать их поможет [описание
модулей](modules.ru.md). В дальнейшем модули, добавленные по URL, можно обновлять
через пункт **Обновить модули**.

## Добавление собственных правил

1. Скопируйте файл [`shadowrocket/custom/custom.example.conf`](../shadowrocket/custom/custom.example.conf).
2. Переименуйте копию в нижнем регистре через дефисы, например `my-services.conf`.
3. Добавьте правила по [инструкции по синтаксису](manual.ru.md).
4. Перед публикацией запустите проверку:

   ```bash
   ./scripts/validate-configs.sh
   ```

5. Сохраните файл в своём репозитории и импортируйте его Raw URL по инструкции
   для модулей выше.

Никогда не публикуйте в модуле секреты, данные прокси, URL частных подписок или
адреса личных серверов.

## Проверка результата

- устройства и сервисы локальной сети продолжают работать;
- российские сервисы, которым нужен российский IP, используют `DIRECT`;
- выбранные зарубежные сервисы используют `PROXY`;
- авторизация, банки, медиасервисы и мессенджеры продолжают работать;
- модуль можно выключить и снова включить без поломки основной конфигурации.

Если маршрутизация работает неправильно, сначала отключите последний добавленный
модуль и проверьте его порядок. Shadowrocket применяет правила сверху вниз:
более общее раннее правило может перекрыть конкретное позднее.
